# Wbox 0.6.0

## Android

- 重建为 Compose / Material 3 界面，启动按钮位于右下角，连接后的停止操作位于底部状态栏。参考 sing-box for Android 的导航、配置选择、流量卡片、状态栏与底部面板；移植其 LineChart。继续使用与桌面端一致的黑白灰配色。
- 保留配置/节点两个工作区、远程配置、自定义名称、订阅、节点编辑与克隆、国旗、延迟测试、分应用代理和彩色日志。
- 修复普通应用权限下 sing-box 自动网卡探测触发 `netlink socket in Android is banned` 的启动失败。Android VPN 已排除自身 UID，运行配置不再要求内核执行网卡探测或桌面网卡绑定。源配置保持不变。
- 保存启动阶段错误；关闭服务不再覆盖失败原因或重复打印关闭日志。
- 节点、连接和日志使用 LazyColumn；界面采样只在前台进行，后台采样保持 30 秒；发布版启用 R8 与资源裁剪。

## Windows

- 托盘在首次绘制前应用主题，等待字体与已渲染帧后显示，修复先浅色后深色的闪烁。
- 启动按钮恢复图标尺寸，连接后的宽度由时长文字自然撑开。
- 二维界面使用软件渲染，关闭主窗口或托盘后 1.5 秒释放对应页面。内存读数改为应用私有内存，避免共享页被多个进程重复累计；内核单独显示。

## 验证

验证记录见同版本 `docs/verification/` 文件。Windows 打包版通过 42 项交互检查；Android 包含配置与交互单元测试、Lint 及模拟器实际 VPN 回归。Android 模拟器测试使用 x86_64 调试构建验证平台权限与 VPN 转发；发布包仍仅包含 ARM64。实体手机、厂商省电策略与 16 KiB 页设备的表现需要对应设备验证。

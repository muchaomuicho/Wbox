# Wbox 0.7.9

在设置中检查 GitHub 正式版更新，确认后下载并显示进度与速率。下载界面可以收起，再从设置中打开。

- Windows 在主进程下载，隐藏窗口不影响下载；校验安装包后启动安装器，安装结束后清理本次下载文件。
- Android 使用系统下载与安装服务，校验包名、版本、SHA256 和原签名后交给系统安装；安装文件不长期留在下载目录。
- 更新失败、取消或权限未授予时保留清楚的恢复入口。
- Windows 合并重复状态请求，移除未使用的打包依赖；Android 低内存时清空图标缓存引用。下载采用流式写盘，避免整包占用内存。

Android versionCode 29，继续使用原签名；双端版本均为 0.7.9。内核保持 mihomo 1.19.33 与 sing-box 1.14.4-wbox.1，保留 26 份离线规则。

验证记录位于 `verification/0.7.9-*`。

# Wbox 0.7.7

两端节点工作区单击即可真正选定：未连接时只保存选择，已连接时自动切换到新节点。菜单更贴近操作位置，Windows 配置卡片也更紧凑。

- Android 节点单击选定，不再依赖双击；三点与长按打开按钮旁的悬浮菜单，支持系统返回关闭。菜单仍提供明确的“连接此节点”入口。
- Windows 节点单击保存选择，右键只打开目标节点的菜单；双击、Enter 与“连接此节点”可显式启动。
- Windows 配置卡片整张支持右键，动作与三点菜单一致；菜单在光标旁展开，靠近窗口边缘时自动避让。
- Windows 配置卡片收紧留白与间距，保持字号；代理页节点卡片的延迟数字移到更靠右下的位置，与协议文字对齐。
- 保留测速期间的选择、重复选择不重启及停止优先的保护，不增加“已选择节点”提示。

Android versionCode 27，继续使用原签名；双端版本均为 0.7.7。内核保持 mihomo 1.19.33 与 sing-box 1.14.4-wbox.1，保留 26 份离线规则。

验证记录位于 `verification/0.7.7-*`。

# Wbox 0.5.1 — Windows / Android

两端同步更新配置与节点管理界面。Windows 使用官方 sing-box desktop / dashboard 的组件和主题；Android 保留原生 View，使用一致的配色、卡片、圆角输入框与对话框。

## 界面与操作

- 添加入口移入配置／节点卡片的 `+`，概览卡片也可直接添加。窗口右上角不再放置“导入”。
- 添加配置、添加节点、编辑节点、测试地址统一使用上游输入框、下拉菜单、按钮与对话框。卡片之间保留统一间距。
- 修复工作区下拉菜单被按钮宽度限制、勾选列挤掉文字的问题；菜单根据内容扩宽并限制在窗口范围内。
- 统一“订阅地址或节点链接”入口。订阅地址下载并更新一组节点；节点链接直接包含节点参数，例如 `ss://`、`vless://`。自动识别 HTTP(S) 订阅、节点列表、Base64、原生 JSON/YAML 节点列表。
- 节点工作区中按 `Ctrl+V` 直接导入剪贴板文本；正在编辑输入框或对话框时保留普通粘贴行为。不会定时读取剪贴板。
- 单击选中行，双击／Enter 设为当前节点。右键菜单支持编辑、设为当前、克隆为手动节点与移除；`Ctrl+D` 编辑当前行。
- 编辑表单按协议显示地址、端口、UUID、认证、传输与 TLS 参数；原生节点可编辑完整 JSON，保留内核专有字段。来自订阅的节点保留其来源，下次订阅更新会覆盖修改；可先克隆为手动节点。
- 延迟测试独立成卡，支持自定义测试地址和恢复 Apple 默认地址。
- Android 同步卡片内添加、自动识别订阅与节点链接、粘贴按钮、双击启用、长按编辑与克隆／移除。连接时也能修改节点；外接键盘支持 Ctrl+V、Ctrl+D、Enter，鼠标支持右键菜单。来源选择使用能完整显示文字的列表。手机输入框中的粘贴保留普通编辑行为。

## 数据与连接

节点编辑校验端口、UUID、传输和配置生成，过期的编辑窗口不能覆盖之后的修改。连接期间添加、编辑、移除节点会重启当前节点内核；启动失败则恢复原数据和原连接。配置工作区运行时修改节点库，不重启配置连接。删除最后一个节点会停止节点连接。

保留已有的 WinINet 恢复流程：先恢复系统代理，再停止内核。两个工作区及所选核心仍分别保存，切换工作区或核心前需停止连接。

匿名 HTTP 代理与普通订阅 URL 可能形式相同：单行、不带凭据和片段的 HTTP(S) URL 按订阅地址处理。导入匿名 HTTP 代理时可附加 `#节点名称`，或使用原生节点 JSON。

## 验证

69 项配置与双内核检查通过，包含新增节点编辑、参数保留、无效输入及原生 JSON 测试。桌面自动化使用隔离数据与本地模拟订阅，验证真实剪贴板快捷键、单击／双击、右键编辑、运行中编辑失败恢复、订阅导入、测试地址、菜单文字、深浅主题、顶部停止与托盘。Windows 打包版 33 项界面检查通过，结果见 `verification/0.5.1-desktop.json`。Android 39 项测试通过，1 项真实外部订阅测试跳过，Lint 无错误；覆盖编辑持久化、原生字段、失败恢复、取消后不重启、剪贴板、双击、长按编辑、两种屏宽与深浅色渲染。Android 生成配置的 HTTP / SOCKS5 UDP、IPv4 / IPv6 转发通过固定版本的 Windows 核心验证。结果见 `verification/0.5.1-android.json`，截图在 `previews/0.5.1-*.png`。

Android 真机 VPN、耗电、连接时编辑的设备行为及 16 KiB 页兼容性尚未验证。窗口渲染测试与保存／恢复逻辑测试不能替代这些设备测试。

安装程序自带 Electron 和 .NET 运行库，可覆盖升级原 Wbox 安装并沿用原数据目录。源代码及许可证随包提供。内核版本保持 mihomo 1.19.33、sing-box 1.14.4；完整功能与已知限制见 README 和 0.5.0 发布说明。

# Wbox 0.6.4

- 两端已连接按钮增加柔和绿色底色与高对比文字，Android 改为实心停止图标；时长按内容自然撑开。
- Android 打开连接、代理组时立即请求首屏快照，等待期间显示加载状态。Windows 启动完成后立即刷新订阅中的连接和代理组数据，初始化期间不显示虚假的空列表。
- Android 大代理组按行惰性创建节点卡片，折叠后的延迟方块改用分块画布；跳过 `all: null` 等非节点组对象，并区分列表键的命名空间。Windows 超过 200 节点的展开组只创建可见卡片。
- Windows 连接行显示进程图标，按需读取本地 EXE 图标并限制缓存。Android 隧道记录 SOCKS 端口对应的原始连接，使用 Android 10+ 的 `getConnectionOwnerUid` 查询应用，并按需加载小尺寸图标。Android 8/9、共享 UID、已结束或无法识别的连接显示通用图标。

默认配置工作区、默认日志自动滚动、双内核和独立节点工作区保持不变。

已通过 Windows 打包版 78 项交互回归、77 项核心基础检查与 14 项转发检查；Android 57 项单元／界面测试中 56 项通过、1 项可选测试跳过，Lint 通过。Android 15 模拟器通过双内核 TCP／UDP、停止后网络恢复、重连、真实应用来源识别和 2,000 节点代理组反复打开验证。

验证见 `docs/verification/0.6.4-*`。模拟器使用 Android 15 x86_64、R8 调试构建；发布包仍仅 ARM64，沿用正式签名。实体手机、耗电和 16 KiB 页设备仍需实机验证。

宝可梦订阅地址在本轮环境中连接／TLS 握手超时，未能重新下载。本轮使用大量节点合成配置与异常组数据进行回归；不能据此确认该手机上的所有闪退原因都已消除。

# Wbox 0.6.10

本次 Android 更新节点测速交互。Windows 仅同步版本号，界面与功能保持 0.6.9。

- Android 代理卡片底部的闪电、延迟数值或 Timeout 区域均可点击，单独测试该节点，点击不会切换当前节点。节点工作区列表同步支持。
- 单节点测速支持未连接与已连接状态。点击嵌套策略组卡片时，仅测试其当前所选节点；页面测速按钮继续测试整组。测速进行时显示圆形进度指示，不再显示“测试中”文字；原有取消按钮保留。
- Android 节点协议名称统一为大写（如 SSH、VLESS、HTTP），直连统一显示 `Direct`，策略组保留 `Selector`、`Fallback` 等原有写法，测速前后保持一致。
- 双端版本为 0.6.10；Android versionCode 为 18。沿用 0.6.9 的 mihomo 1.19.33 和定制 sing-box 1.14.4-wbox.1。

本地单元测试和模拟器回归记录位于 `docs/verification/0.6.10-*`。Android 测试使用项目专用 API 35 x86_64 模拟器，发布包为 ARM64；尚未进行本轮实体手机测试。

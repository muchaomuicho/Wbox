# Wbox 0.7.1

操作更顺手，配置立即生效。Windows 与 Android 的测速、连接和配置管理拆开处理：测速时可以启动内核、停止连接和选择节点；运行环境变化时清理已失效的测速任务，避免旧结果落入新的配置。

- 当前配置的编辑、同步与切换立即应用到运行连接；内核、工作区及影响运行的设置按实际需要重载。配置无效或新内核启动失败时，恢复原数据和原连接。
- Android 配置与节点订阅采用大圆角卡片，集中显示流量、剩余量、有效期和更新时间。每张卡片提供编辑、预览、同步、更多和删除菜单；右上角支持全部更新与默认、名称、最近更新排序，排序选择会保存。
- Android 主界面、订阅编辑、配置编辑和预览统一系统栏背景与主题，修复浅色编辑页顶部黑块。保留原生文本选择与剪贴板操作。
- Windows 配置与订阅卡片同步提供操作菜单、预览、全部更新和排序；连接与测速独立调度，长任务期间仍可获取运行状态和发起停止。
- 重载期间点击停止会取消新连接、恢复原配置并保持断开；取消测速不会误停正在启动的主内核。下载期间的旧响应也不会覆盖新编辑的配置。
- 节点工作区仍只加载当前节点和显式依赖；保留模板分流、26 份离线规则、双内核实际请求延迟、透明测速背景、红色 timeout 和 Windows 托盘交互。

Android versionCode 21，继续使用原签名；Windows 与 Android 版本均为 0.7.1。内核仍为 mihomo 1.19.33 和 sing-box 1.14.4-wbox.1。

验证记录见 `verification/0.7.1-*.json`。Android 使用隔离 API35 x86_64 模拟器验证界面与运行逻辑；ARM64 发布包另做签名、ABI、内核和资源校验。模拟器验证不替代真机耗电、低内存及 16 KiB 页设备验证。

# Wbox 0.8.0

Windows 界面采用与 Android 一致的圆角卡片与中性色调，同时保留桌面操作习惯。本版本为正式版。

- 黑白灰作为主色，雾蓝与柔粉只用于图标、按钮、选中项等点缀；背景保留轻微色调。
- 启动／停止改用标题栏左侧的图标，保留悬停提示、运行时长和键盘可达性。
- 概述去掉独立服务状态框，各栏目去掉标题栏中重复的小标题。
- 缩减标题栏高度与正文顶部间距，左侧 Wbox、版本和工作区保留适当顶部留白。
- 工作区选择放入侧栏；保留右键菜单、配置拖拽、节点单击选择及双击／Enter 连接。

Android 仅同步版本号至 0.8.0（versionCode 30），UI 与功能不变，继续使用原签名。双端内核保持 mihomo 1.19.33 与 sing-box 1.14.4-wbox.1，保留 26 份离线规则。

验证记录位于 `verification/0.8.0-*`。

# Wbox 0.7.4

选择节点和配置时，延迟测试继续进行。

- Windows 与 Android 的完整配置测速使用独立快照和临时内核，选择节点、切换配置及启动连接可同时进行。结果按来源保存，避免新配置显示旧配置结果；显式取消与停止仍优先执行。
- 排查概览、配置卡片、节点列表、代理组和托盘等选择入口，取消节点选择成功提示，保留失败反馈。
- Android 统一连接、分应用代理等底部拉起界面与系统栏的背景和边角，消除贴顶时左右角的灰色缺口，保留半屏拉起的圆角。
- Android 分应用代理显示真实应用图标，保留搜索、选择与保存；图标随可见项异步加载并限制缓存。
- Android 底部面板返回时优先收起搜索键盘，再关闭面板。
- 测速临时内核隔离订阅节点与规则缓存，按声明名称对应资源，保留已转换的内置规则格式；使用测试开始时的来源与专用测速接口，同名且无法区分来源的节点会明确提示，避免显示错误结果。
- Windows 概览和概览项目管理移除系统 HTTP 代理开关；设置统一提供“系统代理”和“TUN 模式”。TUN 模式沿用配置中的 TUN 入站，需要管理员身份运行。

Android versionCode 24，继续使用原签名；Windows 与 Android 版本均为 0.7.4。内核保持 mihomo 1.19.33 与 sing-box 1.14.4-wbox.1，保留 26 份离线规则。

验证记录位于 `verification/0.7.4-*`。Android 使用隔离 API35 模拟器，发布 APK 另核对签名、ABI、内核及离线资源。

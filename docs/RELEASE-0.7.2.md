# Wbox 0.7.2

配置页更清楚，编辑与预览更顺手。

- Android 配置页按 FlClash 的配置列表结构重做：单一顶栏集中更新、排序与添加；卡片突出名称、流量与选中状态，手机单列、平板自适应多列。保留同步、编辑、预览、订阅选项、导出与删除；添加入口包括链接、文件和剪贴板。
- Android 采用中性底色与蓝色主色，柔和粉紫用于到期等辅助信息；同步提高流量、剩余与更新时间的可读性，跟随系统字体缩放。
- Android 配置编辑加入快速滑动后的惯性滚动，保留原生选择、剪切、复制与粘贴。配置编辑、预览与订阅编辑作为完整页面处理系统返回；键盘优先收起，有修改时确认是否放弃，保存期间避免重复操作。
- Windows 配置预览使用 JSON／YAML 语法高亮、行号、查找和自动换行；编辑与预览随窗口大小调整，深浅色及系统缩放下保持可读。
- Windows 配置与订阅卡片的流量、剩余、到期和更新时间放大到 14px，提高对比度与行距，窄窗口允许换行。外观可选黑白、雾蓝和柔粉。
- Windows 托盘右键菜单优先显示在图标左侧，子菜单向左展开；靠近屏幕边缘时根据可用空间调整，并限制在当前显示器内。

Android versionCode 22，继续使用原签名；Windows 与 Android 版本均为 0.7.2。内核保持 mihomo 1.19.33 与 sing-box 1.14.4-wbox.1，保留 26 份离线规则。

验证记录位于 `verification/0.7.2-*`。Android 界面验证使用隔离 API35 模拟器；ARM64 发布包另核对签名、ABI、内核及离线资源。模拟器结果不代替真机验证。

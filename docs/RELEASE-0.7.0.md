# Wbox 0.7.0

Windows 托盘左键单击直接打开或恢复主界面，右键显示托盘菜单。窗口最小化、关闭后释放界面时也能通过左键恢复。

- Windows 节点工作区、配置代理卡片和托盘的测速失败统一显示红色 `timeout`。保留透明测速背景和 11px 延迟文字。
- 节点工作区连接后，托盘“组”显示运行内核的真实模板组，包括节点选择、Microsoft、AI、Steam 等，支持分流切换、组测速、全部测速和关闭所有连接。
- 主界面仍使用独立节点列表。托盘操作不加载整个节点库；只运行当前节点和明确依赖。组选择按内核保存，重启后恢复，切换节点时仍指向新的当前节点。
- 托盘“全部测速”合并所有组并按实际出站去重，避免多个并发请求被忙碌状态跳过。测速结果同步到当前节点列表。
- Android 功能保持 0.6.11，版本号同步为 0.7.0（versionCode 20），使用原签名重新构建，可覆盖升级。

保留 sing-box 1.14.4-wbox.1、mihomo 1.19.33、离线规则、订阅编辑和流量信息、IPv6 默认开启以及既有体积优化。

验证记录见 `verification/0.7.0-*.json`。Windows 使用本地合成代理和隔离数据验证双内核；发布前检查打包程序、Android ABI/签名和内置资源哈希。Android 本次仅改变版本标识，不新增功能或真机验证。

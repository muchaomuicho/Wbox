# Wbox 0.7.8

精简两端节点菜单，并统一批量测速时的转圈反馈。

- Windows 节点右键菜单移除“连接此节点”，保留编辑、克隆和移除；“移除节点”统一标红。
- Android 节点三点菜单移除“连接此节点”“设为当前节点”“测试延迟”，仅保留编辑、克隆和红色移除。
- 两端批量测速开始时，所有本次目标立即显示转圈，包括仍在排队的节点；结果返回后逐个显示新延迟。节点工作区与配置代理组均适用，未参与的节点保持原样，取消或失败后结束待测状态。
- 保留单击离线选择、在线切换、测速期间选择和菜单原生返回。

Android versionCode 28，继续使用原签名；双端版本均为 0.7.8。内核保持 mihomo 1.19.33 与 sing-box 1.14.4-wbox.1，保留 26 份离线规则。

验证记录位于 `verification/0.7.8-*`。

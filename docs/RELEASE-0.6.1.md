# Wbox 0.6.1

Windows x64 / Android arm64-v8a，同步更新。

- 配置与节点工作区保持独立；只生成当前节点及其明确依赖，无关节点错误不再阻止启动。
- 两端的远程配置与节点订阅统一默认使用 `clash.meta/1.19.33`（mihomo）UA。下载后按实际 JSON / YAML 自动匹配内核。
- Android 代理组改为分组卡片与双列节点网格，统一浅色／深色主题，第一组默认展开，其余折叠为延迟色块。
- 两端不再列出 GLOBAL 组。sing-box 按规则运行，不提供 Clash 模式切换；mihomo 保留规则、全局、直连。全局模式优先沿用 MATCH 规则出口，或首个代理组。
- 延迟测试按节点隔离，结果更新后再结束忙碌状态；并行数限制为 4。
- Windows 去掉启动前额外的内核检查进程；Android 去掉界面重复编译配置，改用轻量控制接口探测就绪。
- Windows 配置编辑器扩大，Android 配置编辑器全屏，提供 JSON / YAML 语法颜色与行号。
- 节点密码可以显示／隐藏；Windows 连接详情避开标题栏控制按钮。

## 验证

- Windows：76 项基础与隔离检查、14 项真实内核转发／模式检查通过；打包版 61 项界面检查通过，包含测速结果与动画同步、配置编辑器大小与颜色、密码显隐、托盘首帧主题、工作区隔离、默认 UA 和停止恢复。
- Android：41 项测试通过，1 项按条件跳过；lint 无错误。Android 15 x86_64 模拟器的混淆调试包通过两内核 TCP／UDP VPN 转发、停止恢复与重连；全屏编辑、键盘布局、代理组和深浅色主题已截图核对。
- 用户提供的订阅地址：默认 mihomo UA 返回 HTTP 200，解析出 31 个节点；完整 YAML 在补齐其 GeoIP／GeoSite 依赖后通过 mihomo 原生校验。测试响应与凭据不随源码交付。
- 启动样本：本机 Windows 本地测试配置约 0.53–0.74 秒；Android 模拟器约 0.43–0.44 秒。这不是手机实测或网络订阅首次下载的承诺。远程规则、GeoIP／GeoSite 初次下载仍取决于网络；本次订阅首次校验含数据库下载约 2.7 秒。

Windows 使用官方 desktop 的 Electron 前端，依然有框架内存成本；隐藏主窗口会释放界面渲染进程。不要将应用总内存与其他客户端仅展示的内核／Go 堆内存直接比较。Android 真实手机、厂商输入法、耗电和 16 KiB 页设备仍待实测。

编辑器保存的是当前配置内容，不会修改工作区的节点列表；旧版已存在的节点不自动删除。原生格式节点保留对应内核的完整参数，不进行有损跨内核转换。

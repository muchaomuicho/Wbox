# Wbox 0.6.7

Windows 与 Android 常设“代理”页面，按配置声明顺序排列代理组标签，下方显示节点卡片，右下角悬浮按钮用于测速或取消。断开连接时仍可浏览和测速；测速仅临时启动回环内核，结束后释放，不启用 VPN、TUN 或系统代理。

测速会解析嵌套组的当前实际节点，失败结果显示 Timeout；配置和测试地址变化时清除旧结果。两端保留配置中的原始分组顺序。

Windows 登录时创建完整应用及托盘，增加登录初期托盘重新注册；静默设置只作用于自启，手动启动可正常打开窗口。重复打开已有实例也会恢复窗口。

保留随包离线双内核与全部内置规则。Android 将随附地理数据库无损压缩为 XZ，使用 1 MiB 字典并限制解码内存，按配置需要解压，解压后仍验证原始 SHA-256。清理当前运行目录中不再使用且校验值与随附版本完全相同的数据库，保留自定义内容。内置广告规则由 YAML 编译为 MRS，体积从 2,759,044 字节降至 873,008 字节；在运行副本中替换格式，用户原始配置保持不变。固定规则通过硬链接在多个配置间共享，文件系统不支持时保留普通副本。

Windows 安装程序对安装目录启用系统 LZX 透明压缩以减少实际磁盘占用；应用文件内容不变，非支持文件系统保留正常安装。安装程序体积与安装后的占用是不同指标。

发布版本为 Windows x64 与 Android ARM64，APK 沿用现有签名证书。两个官方内核本身已移除调试符号；为保留完整功能，本版继续使用固定版本的官方内核。

验证结果与体积测量见 `docs/verification/0.6.7-*`。Windows 覆盖打包版代理页面、嵌套组测速、静默启动、透明压缩后启动与双内核转发。Android 覆盖单元测试、Compose 页面测试、Lint、模拟器断网数据库启动及发行包检查；模拟器使用 x86_64 调试构建，发行包仍仅包含 ARM64。尚未测量用户手机安装后的实际占用。

本机 Windows 程序目录透明压缩前为 549,692,583 字节，压缩后实际分配为 217,255,526 字节，文件哈希保持一致。Android 两个官方内核及隧道解压后仍共 147,082,344 字节；APK 大小、系统编译数据和配置运行数据需要分别计算。

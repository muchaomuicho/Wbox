# Wbox 0.6.6

- Windows 管理员运行时使用当前用户的登录计划任务自启，保留静默启动；普通运行使用带完整路径的登录启动项。升级后首次启动会更新已有自启设置。
- Windows 安装器使用简体中文；完成页通过 ShellExecute 启动应用，支持系统兼容性设置中的“以管理员身份运行”。需要提权时由 Windows 显示 UAC。
- 配置与节点订阅继续使用 mihomo 的 `clash.meta/1.19.33` UA。下载遇到 502/503/504、连接失败或超时最多重试一次，并显示中文原因；Windows 交错尝试 IPv6/IPv4 连接。用户取消保持取消语义。
- Windows 连接列表移除应用图标，Android 保留。Windows 节点卡片悬停显示完整名称；Android 长按显示可滚动、可复制的完整名称，节点工作区保留编辑等操作。
- 托盘菜单关闭后缓存 60 秒，再次打开复用窗口；超时释放页面。主窗口关闭后仍在 1.5 秒后释放。
- 独立节点测速使用精简配置，省去规则数据库、嗅探与 FakeIP 缓存；Windows 最多两个临时内核，Android 一个，降低内存峰值。两内核均可保存自定义 HTTPS 测试地址；mihomo 另支持 HTTP。sing-box 上游会替换 HTTP 地址，客户端因此明确拒绝，避免实际测了另一个地址。
- sing-box 与 mihomo `unified-delay` 的计时口径不同：后者可用同一连接的第二次请求计时。较低数字不等于实际网络更快；本版保持内核真实结果，不对读数打折。
- Windows 后台裁剪未使用的 .NET 运行库，Electron 仅保留中英文语言资源。Android 保留 ARM64 双内核，发布包启用 R8、资源裁剪和原生库压缩。
- Android 界面不可见时停止统计轮询，内核退出用阻塞等待通知；保留网络变化回调和 VPN 服务，不持有唤醒锁。前台概览和连接页每秒刷新，其余页面每 5 秒采样。

验证结果与测量记录见 `docs/verification/0.6.6-*`。Android 实体手机的整夜耗电、低内存表现和 16 KiB 页设备兼容性尚未验证；包压缩不代表运行时内存同比下降。源码研究依据见 `docs/RESEARCH-0.6.6.md`。

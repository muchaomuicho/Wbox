# Wbox 0.5.0 — Windows / Android

Windows 前端迁移到官方 `SagerNet/sing-box-for-desktop` / `sing-box-dashboard` 源码。复用原版导航、标题栏、概览、代理组、连接详情、日志、字体与主题；Wbox 增加配置和节点两个独立工作区，保留双内核。

## 修复

- 停止前通过 WinINet per-connection API 恢复系统代理；恢复失败时保留内核和恢复记录。
- 以启用状态和代理端点判断所有权，绕过列表变化不再导致遗留指向已停止端口的代理。不覆盖其他软件已更换的端点，不恢复已经失效的旧本地代理。
- 启动恢复、异常退出恢复和退出清理；正常退出先关闭页面请求，再关闭后台输入流，修复 `ERR_STREAM_WRITE_AFTER_END`。
- 后台 JSON 通道固定使用 UTF-8，保留中文和国旗名称。
- 修复 mihomo 不接受 UTF-16 代理项转义导致含国旗的节点配置无法启动；生成配置保留实际 Unicode 字符。

## 功能

- 远程 / 本地 JSON 与 YAML 配置，自动识别内核，更新、编辑、导出。
- 独立节点工作区，订阅和分享链接导入、订阅更新、节点切换、延迟测试与自定义测试链接。
- 原版代理组、连接列表与详情、连接关闭、日志和流量波形。内核及界面后台内存分开显示。
- 开机自启、静默启动、自动连接、托盘。隐藏窗口停止页面采样，30 秒后释放界面进程；再次打开恢复页面。
- 托盘直接复用上游 `TrayMenu.tsx` 和样式：连接开关、代理组/节点级联菜单、国旗、测速、关闭所有连接、配置切换、打开与退出。配置切换先恢复系统代理再重启内核；测速请求不再阻塞停止操作。托盘菜单关闭 5 秒后释放。
- Android 同步灰白／深色配色、圆角卡片、单色流量图、分开的界面与内核内存。保留原生 View 与分应用 VPN，增加配置编辑/导出、连接详情/关闭、离线节点测速与批量测试。
- Android 后台采样改为 30 秒，停止后台 PSS 采集，回到前台立即刷新；没有增加唤醒锁。

## 验证与范围

- 双内核回归 61 项通过，含国旗、多协议配置检查、真实本地代理流量、节点切换、IPv6。
- 真实 Windows WinINet 回归 11 项通过，含恢复失败时保持运行、绕过列表漂移、恢复前状态一致性。
- 桌面自动化验证远程导入、国旗字体、组内节点切换、真实连接列表、顶部停止和工作区独立保存。具体结果见 `docs/verification/0.5-desktop.json`。
- Android 30 项配置/导入/界面/连接测试通过，1 项外部真实订阅测试跳过；包括两种屏宽与深浅主题渲染。Lint 无错误。APK 使用原 Wbox 证书签名，ABI 为 arm64-v8a。
- Android 真机 VPN、耗电与 16 KiB 页设备兼容性仍待验证。Android 生成配置的转发测试运行在固定版本的 Windows 内核上。

前端来自 Electron，不能把内核几十 MiB 的读数当成整个软件的内存。界面常驻内存并未证明低于旧 WPF 版本；本次优化重点是后台停止采样并释放界面进程。显示的界面后台内存为相关进程工作集之和，含共享页面重复计数。

安装包包含运行时，不要求目标电脑预装 .NET。仍沿用 Wbox 数据目录，保留旧配置；运行中的配置、工作区和内核切换需先停止。原生 TUN 配置需以管理员身份启动；默认使用受管系统代理入站。源码来源、许可证和构建说明见 `docs/UPSTREAM-DESKTOP.md`。

# Wbox 0.6.5

- Windows / Android 内置指定远程配置与两份模板中的 26 份规则集：sing-box 使用 13 份 SRS，mihomo 使用 12 份 MRS 和一份 anti-ad YAML。运行副本将精确匹配的远程来源改为本地文件，启动不再下载这些规则；源配置不变，其他自定义 URL 不受影响。
- 节点工作区基于用户提供的 JSON / YAML 模板生成配置，保留 DNS、FakeIP、广告拦截、Microsoft、AI、Steam、Steam Download 与国内分流。只插入选中节点及同来源内明确依赖的前置节点，原模板节点、凭据、示例域名与专用地址转发规则均已清除。
- 模板中的 TUN / mixed 入站仍由平台管理：Windows 使用所选代理接入方式，Android 使用 VpnService。不会因模板的 TUN 开关擅自启用第二个隧道。默认出站为“节点选择”，配置工作区和节点工作区继续独立。
- mihomo 会先开放控制接口，再加载规则。两端启动与临时测速现在等规则加载完成后才继续，避免刚显示已连接便出现 502 / 空连接。
- 内置资源用 SHA-256 校验，已有副本不重复写入，损坏副本会从安装包恢复。规则为 2026-11-02 固定快照，随后续软件版本更新；不在每次启动时联网更新。

源码包附带已脱敏模板、规则来源和校验清单、可编辑规则源数据，以及固定版本下载脚本。验证记录见 `docs/verification/0.6.5-*`；Android 使用 Android 15 x86_64 模拟器与 R8 调试构建，发布 APK 为正式签名 ARM64。真机耗电及 16 KiB 页设备未在本轮验证。

Windows 打包版 78 项交互、91 项基础／模板检查及 14 项转发回归通过。Android 59 项测试中 58 项通过、1 项可选测试跳过，Lint 通过。模拟器模板回归分别覆盖 TCP 经过所选节点、私有地址 UDP 按模板直连、停止后的网络恢复和重连。

# Wbox 0.7.3

订阅更新更直观，双端配色与操作更统一。

- Windows 与 Android 的远程配置、节点订阅卡片增加专用圆形更新按钮。点击立即显示连续旋转圆环，短请求也有清楚反馈；每份订阅独立显示状态，更新期间防止重复触发，失败后恢复重试并保留已有内容。
- 顶部保留“全部更新”，覆盖整个批量任务；三点菜单移除重复的“同步”，保留编辑、预览等操作。
- Android 可选黑白、雾蓝与柔粉，分别适配浅色与深色，配色和明暗模式独立保存。
- Android 到期信息移到流量信息旁，字体与颜色保持一致，取消突出的到期标签；流量、剩余与日期继续使用放大的文字并支持系统字体缩放。
- Android 配置页使用与其他页面一致的悬浮启动按钮，启动中可取消，成功连接后才显示连接入口。
- Windows 窄窗口顶部操作自动调整布局，避免更新按钮与工作区入口重叠。

Android versionCode 23，继续使用原签名；Windows 与 Android 版本均为 0.7.3。内核保持 mihomo 1.19.33 与 sing-box 1.14.4-wbox.1，保留 26 份离线规则。

验证记录位于 `verification/0.7.3-*`。Android 界面验证使用隔离 API35 模拟器；ARM64 发布包另核对签名、ABI、内核及离线资源。模拟器结果不代替真机验证。

# Wbox 0.7.6

Windows 自定义光标缩小到接近原生手形的可见尺寸，Android 拉起面板和内部列表到边界后稳定停住。

- Windows 保留圆润的点击、抓取和拖动光标，缩小图形并同步调整点击热点；主窗口和托盘保持一致。
- Android 连接、分应用代理等拉起面板的内容碰到上下边界时不再拉伸后回弹；快速滚回顶部后不再由剩余惯性推动整个面板，直接快拖标题或拉手也停在允许的边界内。保留正常惯性滚动、拖动关闭、系统返回和键盘优先收起。

Android versionCode 26，继续使用原签名；双端版本均为 0.7.6。内核保持 mihomo 1.19.33 与 sing-box 1.14.4-wbox.1，保留 26 份离线规则。

验证记录位于 `verification/0.7.6-*`。

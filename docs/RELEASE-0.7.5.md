# Wbox 0.7.5

配置卡片支持手动拖动排序，日期信息可直接切换显示方式。

- Android 长按整张配置卡片拖动调整顺序，靠近列表上下边缘时自动滚动；Windows 直接拖动配置卡片调整顺序。顺序持久保存，并用于概览的配置选择。拖动不会选择配置或启动连接，订阅更新、增加或删除配置时保留已有顺序。
- Windows 点击和卡片抓取采用圆润的 SVG 悬停光标，支持浅色、深色与高 DPI；文字输入和窗口缩放保留正常指针。
- 双端配置与节点订阅卡片默认显示具体到期日期和“到期”；点击到期时间切换为剩余天数。更新时间默认显示“更新于 X 时间前”，点击切换为具体日期时间。时间显示各自独立，点击不会触发配置选择。
- Android 连接、分应用代理等底部面板的系统返回回调跟随窗口挂载和卸载，保留系统 Back 按键兼容入口。返回优先收起键盘，并保留面板关闭保护和已修复的边角。

Android versionCode 25，继续使用原签名；Windows 与 Android 版本均为 0.7.5。内核保持 mihomo 1.19.33 与 sing-box 1.14.4-wbox.1，保留 26 份离线规则。

验证记录位于 `verification/0.7.5-*`。Android 使用隔离 API35 模拟器，发布 APK 另核对签名、ABI、内核及离线资源。

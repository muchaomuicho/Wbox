# Android 面板滚动边界

Material3 1.2.1 有两种视觉回弹：Android 的 overscroll 绘制会拉伸列表内容；面板的 spring 动画也可以在带初速度时越过锚点。仅关闭 overscroll 后，设备上的顶部回弹仍存在。

`WboxBottomSheet` 在内容范围关闭 overscroll。内容滚动停在当前锚点时，消费剩余纵向 fling 速度，避免静止面板再被惯性推动；实际拖动改变了面板位置时仍由 Material3 处理。程序动画的目标与当前状态不一致时保留原处理。

直接拖动标题或拉手不经过内容的嵌套滚动回调，因此另外在 placement 阶段限制实际位置。Expanded 和 Hidden 使用与 Material3 一致的父高度与面板测量高度，校正为 `boundedOffset.toInt() - rawOffset.toInt()`，与内部 offset 的取整保持一致。测量尺寸和允许区间内的拖动保持原样，圆角使用相同的受限位置。

`SheetFlingUiTest` 逐帧检查面板内容中固定标题的实际位置。外层 modifier 的 testTag 位于 Material3 内部 offset 之前，不能用于证明窗口没有移动。正确测点的对照先失败再通过：剩余 8000 px/s 速度使标题下移 74 px，直接快拖标题或拉手分别向上越界 24 px；最终这三条回归通过。相关 16 条 UI 回归同时检查正常惯性、拖动关闭、返回保护、应用面板与配置排序。

真实 API35 模拟器录像的修改前后逐帧数据见 `0.7.6-android-boundaries.json`。它分别检查内容到顶部和底部、直接拖动标题和拉手、正常惯性、下拉关闭、键盘与系统返回，使用合成配置并恢复原有模拟器应用数据和设置。

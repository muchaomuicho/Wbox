# Android 底部面板返回

Material3 1.2.1 的面板使用独立窗口，系统返回回调必须注册到该窗口的 dispatcher。Wbox 的注册随实际 View 的 attach / detach 变化，销毁时注销捕获的 dispatcher；应用层也明确启用 OnBackInvokedCallback。

保留 API 26–32 和设备兼容路径的 Back 键处理。面板本身提供非文本焦点，首次打开及主动关闭键盘后可继续接收按键；取消的 ACTION_UP 不触发关闭。关闭前先检查 Hidden 是否允许，避免保存期间把受保护的面板移出屏幕后留下遮挡。

回调采用 PRIORITY_DEFAULT，避免 Material3 默认的 PRIORITY_OVERLAY 抢在键盘前执行。IME 与默认回调的实际注册顺序仍由 Android 决定，Wbox 另外检查 IME 可见状态，在自身收到返回时先收起键盘。

`SheetBackUiTest` 在 API 28 / 34 检查禁止关闭时面板仍可见，放行后只触发一次关闭。设备交互记录见 `0.7.5-android-interactions.json`，使用隔离 API35 模拟器的真实左右边缘滑动。

该模拟器的镜像默认关闭系统导航栏，原先只有 swipe-up 监听而没有 edge-swipe。验证时临时设置 qemu.hw.mainkeys=0 并重启 Android framework，确认系统 edge-swipe 监听已启用；未修改 AVD 配置，结束后关闭模拟器。

在启用真实边缘监听后，旧版 0.7.4 的分应用面板也能在此模拟器返回。因此用户手机上的特定失败没有在此镜像复现，本次加固的是明确的窗口生命周期、焦点与关闭保护路径。模拟器通过不代表已验证所有厂商的系统手势实现。

关于 Wbox

你可能还想知道。

反馈问题
Wbox 提供节点或订阅吗？

Wbox 是代理客户端，不提供节点或订阅服务。请导入你已有的节点、订阅链接或完整配置，再开始连接。

我应该选择哪个工作区？

已有完整 mihomo 或 sing-box 配置时，使用「配置工作区」管理、预览和切换配置。想直接管理节点链接及节点订阅时，使用「节点工作区」。两个工作区可在应用内切换。

还需要单独安装内核和下载规则吗？

安装包已经包含 mihomo、sing-box 及内置规则资源。自己的配置若引用了额外的远程资源，则仍按该配置的规则加载。

选择节点会自动开始连接吗？

未连接时，单击节点只保存选择，点击启动后才开始连接。已经连接时，选择另一个节点会应用切换。这样，选择和连接始终各自清楚。

怎样在应用内检查更新？

从 0.7.9 起，Windows 与 Android 都可在「设置」中点击「检查更新」，检查 GitHub 最新正式版。发现新版后先询问，确认才下载。

下载时可查看进度、已下载大小和速率。收起更新面板后下载仍会继续，回到设置点击「查看下载进度」即可重新打开；Windows 隐藏主窗口也不影响下载。

下载完成后，怎样安装和清理？

Windows 完成校验后会关闭 Wbox 并打开安装器，请按提示完成安装；安装器退出后会清理本次安装包。

Android 首次更新可能需要允许 Wbox 安装应用，随后仍需在系统安装器中确认。系统接收完整安装内容后，Wbox 会清理下载副本。

怎样确认安装包完整？

每个版本的发布页提供 SHA256 校验文件。计算下载文件的 SHA256，并与对应文件名的校验值比较即可。
